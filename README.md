# Comando Jurídico Supremo (CJS)

Portal comunitário de simulação jurídica para a comunidade do Discord.

> **Aviso:** este projeto é uma simulação/roleplay. Leis, documentos, editais e jurisprudência publicados no portal são fictícios e não constituem orientação jurídica real.

## Tecnologias
- Next.js
- TypeScript
- Supabase (PostgreSQL e autenticação)
- Discord OAuth (planejado)
- Vercel (hospedagem planejada)

## Estado do projeto
Este repositório está em desenvolvimento. Não publique segredos, tokens, senhas ou chaves privadas.
